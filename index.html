Chat en Vivo con Firebase

Aplicación web de chat en tiempo real desarrollada con HTML, CSS y JavaScript. Permite enviar mensajes de texto e imágenes, editar mensajes y limpiar el historial del chat. Utiliza Firebase Firestore para la sincronización en tiempo real y Cloudinary para el almacenamiento de imágenes.

Tecnologías utilizadas:

  • HTML, CSS y JavaScript
  • Firebase Firestore (tiempo real)
  • Cloudinary (subida de imágenes)
  • Diseño responsive para PC y móviles
